<h2 class="mp-h2" style="border-color:#f28500; background-color:#f8eaba"><span class="mw-headline" id="Important">Important</span></h2>
<div>
<ul><li>Please remember that you <a href="/wiki/Pietspeech" title="Pietspeech">most</a> follow the <b><a href="/wiki/Forks:Rules" title="Forks:Rules">Server Rules</a></b> and read the <b><a href="/wiki/Forks:Criminal_Code" title="Forks:Criminal Code">Criminal Code</a></b>. Please also be aware of the <a href="/wiki/Category:Server_Standards" title="Category:Server Standards">Server Standards</a>.</li>
<li>Please register your alt accounts <a href="/wiki/Forks:Alt_Accounts" title="Forks:Alt Accounts">here</a>! Failure to register them may result in ban! Note that accounts connecting from the same IP, like family members should be registered there too to prevent confusion.</li>
<li>Vote for new mods, server rule changes, <a href="/wiki/Griefer_of_the_Year" title="Griefer of the Year">griefer of the year</a>, etc. <a href="/wiki/Vote" class="mw-redirect" title="Vote">here</a>.</li>
<li>Report railway problems <a href="/wiki/Railway_Problems" class="mw-redirect" title="Railway Problems">here</a>.</li>
<li>Please read and contribute to the <a href="/wiki/Forks:Nieuws" title="Forks:Nieuws">Nieuws</a>. If anything noteable happens, you should report it in the nieuws. History is being lost every day!</li>
<li>The wiki has been migrated. Please report any bugs to admin. Missing uploader names on images is a known bug.</li>
<li>The MT server was moved and migrated on 2024-07-05, please <a href="/wiki/Bugs_after_Server_move" title="Bugs after Server move">report any possible problems or bugs</a>.</li></ul>
